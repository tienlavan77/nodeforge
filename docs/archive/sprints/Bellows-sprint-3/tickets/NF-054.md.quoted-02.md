> ## Ghi Chú Cho Builder
> 
> ### Tại Sao Luồng (b) Quan Trọng?
> 
> Lý do chính từ `ARCHITECTURE.md` mục 66.8 + phiên trao đổi mới:
> 
> > **"Agent không giao tiếp trực tiếp với nhau qua file trung gian. Builder ghi code trực tiếp. Reviewer đọc code qua Node (Code Index), gửi verdict về Node dưới dạng Event có cấu trúc — không có file handoff."**
> 
> Sprint 3 chỉ test luồng Builder → file. NF-054 bổ sung luồng Reviewer để xác nhận:
> - ✅ Reviewer có thể đọc file (query Code Index)
> - ✅ Reviewer phát verdict qua Event (không file)
> - ✅ Workflow hoàn chỉnh: Builder file → Node detects → Code Index → Reviewer reads → verdict Event
> 
> Nếu bỏ luồng (b), không xác nhận nguyên tắc "no Agent-to-Agent file handoff" — nguy hiểm lúc lên Sprint 6 (Workflow Engine) sẽ tưởng nhầm file trung gian vẫn được dùng.
> 
> ### API Cho Reviewer Để Query Code Index
> 
> Builder cần xác nhận **API nào** Reviewer dùng để đọc file:
> 
> ```javascript
> // Option 1: Node phát context.ready event kèm file content
> // → Reviewer nhận qua stdout, parse Event
> 
> // Option 2: Reviewer call Node API qua HTTP/gRPC query
> // → Cần "đợi Sprint 8 Transport implement"
> 
> // Option 3: Query index.db trực tiếp (SQLite, tạm thời)
> // → Valid nếu API chưa có, nhưng comment "temporary, API TBD"
> ```
> 
> **Ghi rõ trong test:** Builder chọn option nào + lý do.
