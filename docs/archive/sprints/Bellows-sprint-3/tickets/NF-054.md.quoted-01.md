> # NF-054 — Integration Test End-to-End (2 Luồng)
> 
> **Sprint:** 3 (Bridge)  
> **Type:** Integration Test  
> **Estimate:** M (Medium)  
> **Dependencies:** NF-049, NF-050, NF-051, NF-052, NF-053  
> **Phụ thuộc:** Tất cả ticket Sprint 3 đã done phải xong trước (48–53)
> 
> ---
> 
> ## Mục Tiêu
> 
> Build end-to-end integration test xác nhận **toàn bộ chuỗi Agent Protocol** hoạt động đúng từ đầu đến cuối:
> - **Luồng (a) — Builder:** Agent spawn → `sessions.start` → ghi file → Node watcher detect → Code Index cập nhật → `sessions.finish`
> - **Luồng (b) — Reviewer:** Agent khác spawn → đọc file via Code Index (không viết file trung gian) → verdict về Node qua Event có cấu trúc
> 
> **Quan trọng:** Xác nhận **không có file "handoff" trung gian nào** (`review.md`, `builder-report.md`, vv) được tạo ra — Agent giao tiếp qua Node, không file.
> 
> ---
> 
> ## Acceptance Criteria
> 
> ### Luồng (a) — Builder Flow
> 
> - [ ] Agent fixture A spawn đúng (process độc lập, NDJSON wire format)
> - [ ] Agent A gửi `sessions.start` command → Node tạo session record
>   - [ ] Session có `session_id`, `agents: [agent_a_id]`
>   - [ ] `capability_scopes` được validate + lưu (NF-053)
> - [ ] Agent A ghi file thật vào project fixture: `src/auth.js` (mock code)
>   - [ ] File được lưu thực tế trên filesystem
>   - [ ] stdout/stderr capture được qua `internalBus` (NF-051)
> - [ ] Node watcher detect file change (tái dùng Sprint 1 pipeline NF-023 nguyên vẹn)
>   - [ ] File event phát lên `internalBus` (xác nhận không bị dính với agent stream)
>   - [ ] Code Index update (NF-017–022 đã có, chỉ xác nhận index.db có entry `src/auth.js`)
> - [ ] Agent A gửi `sessions.finish` command → Node đóng session
>   - [ ] Session record vẫn tồn tại (readable, không delete — đúng NF-044)
>   - [ ] Process A không còn zombie (PID check lúc finish)
>   - [ ] Không leak handle/file descriptor
> 
> ### Luồng (b) — Reviewer Flow (Mới, không có trong Sprint 3 trước)
> 
> **Context:** Sau luồng (a) xong, file `src/auth.js` đã có trong project fixture + index.
> 
> - [ ] Agent fixture B spawn độc lập (khác session_id với A)
> - [ ] Agent B gửi `sessions.start` command → Node tạo session record riêng
>   - [ ] Session B có `session_id` khác A, `agents: [agent_b_id]`
> - [ ] Agent B **đọc** file `src/auth.js` (qua Code Index, không file trung gian)
>   - [ ] Xác nhận: Agent B dùng API/interface Node cung cấp để query symbol/file content
>   - [ ] **Không** tạo file `review.md` hoặc bất kỳ file trung gian nào
> - [ ] Agent B phát hiện lỗi mock (script fixture chỉ định sẵn 1–2 issue nhỏ trong file)
> - [ ] Agent B gửi `review.requested` event (hoặc tương đương review verdict command)
>   - [ ] Payload có cấu trúc: `{ result: "changes_required", findings: [...], ...}` khớp schema
>   - [ ] Event validate qua Ajv với `core/event.schema.json` (hoặc `node-event.schema.json` nếu Node phát)
> - [ ] Node nhận event → lưu (nơi nào: Event Store hay tạm thời?)
> - [ ] Agent B gửi `sessions.finish` → Node đóng session B
> - [ ] **Filesystem check:** `git status` xác nhận **không có file mới** được tạo
>   - [ ] Chạy `git status` sau cả 2 luồng → chỉ `src/auth.js` modified (từ A), không có `review.md` / `*.md` / bất kỳ artifact nào khác
> 
> ### Toàn Chuỗi (Cross-Luồng)
> 
> - [ ] 2 session hoạt động **độc lập** (không can thiệp lẫn nhau)
>   - [ ] Session A stream **không bị trộn** vào Session B stream
>   - [ ] Request ID / session ID routing đúng (NF-050 idempotency)
> - [ ] Timeout/kill (NF-052) — không xảy ra (fixture tính toán thời gian)
> - [ ] Concurrent modification (NF-055) — **nếu 2 agent cùng lúc sửa 1 file:**
>   - [ ] Node phát warning event (NF-055 milestone, nhưng xác nhận không gây crash ở NF-054)
>   - [ ] Cả 2 lần ghi vẫn thành công
>   - [ ] Cả 2 session vẫn close sạch

> ### Fixture `agent-builder.js` Pseudocode
> 
> ```javascript
> // Spawn bởi test runner
> const Agent = require('../../src/modules/agents/agent-process');
> 
> async function runBuilder() {
>   const session = {
>     command: 'sessions.start',
>     capability_scopes: { profile: 'ai', scopes: ['read_code', 'write_code'] }
>   };
>   
>   // Send via stdin
>   console.log(JSON.stringify(session));
>   
>   // Receive session_id via stdout
>   const response = JSON.parse(await readStdout());
>   
>   // Write file
>   require('fs').writeFileSync(
>     'src/auth.js',
>     'function login() { /* mock */ }'
>   );
>   
>   // Stream output
>   console.log('Building auth.js...');
>   
>   // Finish session
>   const finish = { command: 'sessions.finish' };
>   console.log(JSON.stringify(finish));
> }
> 
> runBuilder().catch(console.error);
> ```
