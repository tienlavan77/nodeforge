# Modal migration inventory

`components/Dialog.jsx` owns shared presentation, portal mounting, focus containment/restoration, Escape, and outside-click behavior. Each caller remains the single owner of open/close and domain state; do not duplicate it inside `Dialog`.

| Existing modal | Current owner | Migration path |
| --- | --- | --- |
| Add/edit agent | `app/agents/page.jsx` (open/edit state and form lifecycle); `components/AddAgentModal.jsx` (form presentation) | Already uses `Dialog`; keep form data and save lifecycle in the page. |
| Create conversation | `ConversationsAccordion` in `components/ConversationsAccordion.jsx` owns `modalOpen`, title, validation, and create/close lifecycle; `components/CreateConversationModal.jsx` renders the modal | Replace its portal/backdrop/dialog wrapper with `Dialog`; retain conversation form and `modalOpen` ownership in `ConversationsAccordion`. |
| Ticket detail/edit | `TicketCard` in `components/ticket-detail-modal.jsx` owns `viewOpen`, ticket detail, and refresh lifecycle; `TicketModal` renders the detail editor | Replace the modal shell with `Dialog`; keep detail/edit state in `TicketCard` and its existing callbacks, with no second open-state store. |
| Create conversation (workspace panel) | `ConversationModal` in `components/NodeForgePanels.jsx` owns the existing `role="dialog"`/`aria-modal="true"` shell, title, submit status, error state, and supplied `onClose`/`onCreated` lifecycle | Replace only the overlay and dialog shell with `Dialog`; keep title, request status, error, and callbacks in `ConversationModal`, with no duplicate state in the primitive. |
| Upload sprint plan | `UploadSprintPlanDialog` in `components/NodeForgePanels.jsx` owns the existing `role="dialog"`/`aria-modal="true"` shell, file, parsed plan, validation errors, upload status, and supplied `onClose`/`onUploaded` lifecycle | Replace only the overlay and dialog shell with `Dialog`; keep file parsing, preview, validation, upload status, and callbacks in `UploadSprintPlanDialog`, with no duplicate state in the primitive. |
| Conversation and audit history | `HistoryOverlay` in `components/agent-workspace-overlays.jsx` owns history filters, loading/error/result state, and the supplied `onClose` callback | Replace the overlay shell with `Dialog`; keep history query state, client loading, rendering, and close ownership in `HistoryOverlay`, with no duplicate open state in `Dialog`. |
| Agent settings | `AgentSettingsOverlay` in `components/agent-workspace-overlays.jsx` owns provider/model/API-key form state, save/test status, and the supplied `onClose` callback | Replace the overlay shell with `Dialog`; keep agent settings form state, client mutations, status messaging, and close ownership in `AgentSettingsOverlay`, with no duplicate open state in `Dialog`. |
| Entity details | `EntityDetailsModal` in `components/ticket-detail-modal.jsx` owns the portal-backed detail shell, title, loading/error state, backdrop close handler, and supplied `onClose` callback | Replace the portal/backdrop/dialog wrapper with `Dialog`; keep ticket detail content, loading/error state, and the caller’s close lifecycle in `EntityDetailsModal`/`TicketCard`, with no duplicate state in the primitive. |

All listed modal presentations have an identified owner and path to the shared primitive. `CreateConversationModal.jsx`, `ticket-detail-modal.jsx`, `agent-workspace-overlays.jsx`, `ConversationModal`, and `UploadSprintPlanDialog` are confirmed modal users; migration of those legacy callers is separate from introducing the primitive.
