# NodeForge agent instructions

## Code summary comments

- Khi tạo file mới, đặt một comment summary ngắn ở đầu file.
- Khi tạo function mới, đặt một comment summary ngắn ngay trước dòng định nghĩa function.
- Summary mô tả mục đích của file hoặc function, không diễn giải từng dòng code.
- Không thêm summary vào file hoặc function cũ nếu không tạo mới.
- Summary phải dùng cùng ngôn ngữ với code của file và không chứa thông tin bí mật.
